# Agent Workflow: Trigger to Verified Close

## 1. PREPARE — Rules Before Any Run

### Choose the simplest shape that passes

### Assign roles, risk tiers and limits

### Define done as checkable system state

### Test success and adversarial cases first

### Raise autonomy only on evidence

## 2. ADMIT — Task, Identity, Boundary

### Deduplicate triggers into one task record

### Authenticate requester, name the acting principal

### Sandbox execution, keep credentials outside

### Arm turn, spend and time limits

### Keep task state outside the model

## 3. FRAME — Contract Before Action

### Retrieve authorized context as labelled data

### Ask when ambiguous, pin the contract

### Route models and tools by difficulty

### Plan irreversible steps after all checks

### Brief workers without passing write authority

## 4. ACT — One Gated Action

### Gate every call in fixed order

### Bind human approval to exact payload

### Record intent, execute once, read back

### Replan inside contract and limits

### Reconcile before any retry or resume

## 5. CLOSE — Prove, Deliver, Learn

### Verify outcomes independently of the actor

### Deliver results, even partial, with manifest

### Settle after confirmation, allow reopening

### Hand off with a usable package

### Measure cost, curate memory, revisit design
